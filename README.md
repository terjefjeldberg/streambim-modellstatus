# StreamBIM · Modellstatus

Statkraft-widget for MMI-fordeling, proxy-antall og modellfag.

Widgetadresse: https://terjefjeldberg.github.io/streambim-modellstatus/

Åpnes som widget i StreamBIM med automatisk prosjekttilkobling. Standalone-visningen kan kobles til en prosjektlenke eller vise merkede eksempeldata.

Tallene leses fra IFC-originaldokumenter i modellagene. Originalenes revisjon kan avvike fra publisert 3D. Punktskyer inngår i modelloversikten, men telles ikke som IFC-objekter. Prosjektdata behandles lokalt i minnet og lagres ikke permanent.

Fag fra lag- og filnavn merkes som tolket. Manglende og motstridende MMI-verdier vises separat. Lokale biblioteklisenser finnes i vendor/.
